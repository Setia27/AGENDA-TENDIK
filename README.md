# AGENDA-TENDIK
laporan harian tendik

🚀 Cara Instalasi

1. Unduh File Installer
Unduh file instalasi aplikasi (AgendaTendik_Setup.exe atau AgendaTendik.apk) melalui tautan yang telah disediakan.
2. Jalankan File
Klik dua kali pada file hasil unduhan untuk memulai proses pemasangan.
3. Ikuti Petunjuk di Layar
Pilih lokasi penyimpanan (biarkan default jika tidak yakin), lalu klik Next hingga tombol Install muncul.

⚠️ Penting: Mengatasi Peringatan Keamanan Saat Instalasi

Saat menjalankan file instalasi, sistem operasi Anda mungkin akan memunculkan pesan peringatan seperti "Windows protected your PC" atau "Aplikasi tidak dikenal / Sumber tidak terpercaya".
Hal ini adalah wajar karena aplikasi ini dikembangkan secara mandiri untuk kebutuhan internal dan belum didaftarkan ke toko aplikasi resmi (seperti Microsoft Store atau Google Play Store). Aplikasi ini 100% aman digunakan.
Silakan ikuti langkah berikut untuk mengabaikan peringatan dan melanjutkan instalasi:

Jika Menggunakan Windows (Windows SmartScreen):

1. Pada jendela biru bertuliskan "Windows protected your PC", klik tulisan kecil More info (Informasi selengkapnya) di sebelah kiri.
2. Tombol baru akan muncul di bagian bawah. Klik tombol Run anyway (Tetap jalankan).
3. Proses instalasi akan berjalan seperti biasa.

Jika Menggunakan Android (Play Protect / Sumber Tidak Dikenal):

1. Jika muncul pop-up "Demi keamanan, ponsel Anda tidak diizinkan menginstal aplikasi yang tidak dikenal...", klik Setelan (Settings).
2. Aktifkan opsi Izinkan dari sumber ini (Allow from this source).
3. Kembali ke layar sebelumnya, lalu klik Instal.
4. Jika muncul peringatan Google Play Protect, pilih Tetap instal (Install anyway).
